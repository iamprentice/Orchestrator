Complaint-Mining Product Builder

Converts user complaints into startup opportunities using Claude AI

Setup Guide

What It Does

🔍

Mine Complaints

Analyzes Reddit, reviews, forums, and SaaS communities to surface the top frustrations in any product space.

💡

Find Market Gaps

Identifies where existing solutions fail and quantifies the opportunity size (TAM/SAM).

🚀

Generate Startups

Produces ranked startup ideas with confidence scores, revenue potential, and difficulty estimates.

📋

Build MVP Specs

Creates complete specs: features, pricing tiers, go-to-market plan, and week-one action items.

Prerequisites

1

Python 3.9+

Check if you have it:

python --version
If not installed, download from python.org
2

Git

Check if you have it:

git --version
If not installed, download from git-scm.com
3

Anthropic API Key

Get one at console.anthropic.com — you'll need a free account. The key looks like sk-ant-...

Installation (Windows PowerShell)

1

Clone the repository

git clone https://github.com/iamprentice/Orchestrator.git
cd Orchestrator
2

Install dependencies

pip install -r requirements.txt
This installs Claude AI SDK, Rich (terminal UI), Typer (CLI), Pydantic, and more.
3

Set up your API key

Copy the example config file:

Copy-Item .env.example .env

Then open .env in Notepad and replace the placeholder:

notepad .env

Change this line:

ANTHROPIC_API_KEY=sk-ant-your-key-here

Commands

Full Pipeline (recommended)
python main.py full "project management software"
Runs all three stages and saves a JSON report to ./output/
Step 1 — Analyze Complaints
python main.py analyze "CRM software"
Top frustrations, market gaps, TAM/SAM
Step 2 — Generate Opportunities
python main.py opportunities "email marketing"
Ranked startup ideas with confidence scores
Step 3 — Build MVP Spec
python main.py mvp "project management software"
Pricing tiers, GTM plan, week-one actions
Save output to JSON
python main.py full "your niche" --save
Saves full report to ./output/full_report_your_niche.json
With live Reddit scraping
python main.py full "your niche" --reddit
Requires Reddit API credentials in .env (optional)
